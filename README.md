# 🛒 My E-commerce

Веб-приложение интернет-магазина одежды, разработанное на базе Node.js с использованием современных инструментов для серверной логики и интерфейса.

## 🛠 Технологии
* **Backend:** Node.js, Express
* **Стилизация:** Tailwind CSS
* **Архитектура:** MVC / Шаблонизаторы

## 🚀 Быстрый старт

1. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/oktxin/my-ecommerce.git](https://github.com/oktxin/my-ecommerce.git)
Установите зависимости:
Bash
npm install
Запустите проект:
Bash
npm run start
